說明

移動編輯頁

  • 點縮圖或核取方塊選取；Shift 可連續選取。可一次加入多個 PDF 合併。
  • 拖到縮圖左半側，插入該頁之前；右半側插入之後。綠色線條標示落點。拖曳已選頁面會一起移動，靠近畫面邊緣會自動捲動。
  • 「移到第 … 頁」以移動前的頁序作為目標。也可用前移、後移精準調整。
  • 頁碼範圍支援 1-3, 6, 9-。拆分區段以 | 分隔；留白則每頁一檔。

進階編輯模式

  • 左側縮圖或頁碼欄切換頁面；可縮放、適合寬度或展開閱讀器。
  • 填寫註解內容、字級及顏色，按「加註解」，再點頁面放置。選取既有註解即可修改，雙擊註解會定位到文字欄。
  • 「色彩補丁」可選任何顏色，在頁面拖出範圍；直接點一下會建立預設大小。選取後拖曳移動，拖四角改變大小。
  • 補丁與立可白筆畫只是視覺遮蓋，底下的原始文字仍可能被搜尋、複製或取出；並非機密資料的永久塗銷。
  • 註解和補丁會跟隨頁面搬移。旋轉時，註解和補丁會隨整頁一起旋轉；可再調整位置。

畫筆、圖片與浮水印

  • 「畫筆」可連續自由繪製，調整顏色與粗細；按「立可白」切為白色畫筆。每筆可獨立復原，按 Esc 取消正在畫的筆畫。
  • 切回「選取」可移動、改色、縮放或刪除筆畫。物件設定下方可調整物件的上下層次。
  • 「加入圖片」支援 PNG、JPEG、WebP、BMP 與 GIF（靜態畫面）。圖片保留透明背景，可拖移、縮放及調整不透明度；預設鎖定長寬比。
  • 浮水印可設定文字、顏色、字級、角度、不透明度、九種位置或重複鋪滿，並限定頁序範圍、奇數頁或偶數頁。右側預覽目前頁面；套用前按取消不會變更文件。
  • 浮水印位於原頁上方、註解與補丁下方；頁碼、頁首及頁尾仍保持清楚。所有新增內容都會包含在 PDF 與 ZIP 匯出中。

頁碼、頁首與頁尾

  • 設定立即顯示於縮圖與閱讀器，所有匯出方式都會套用。
  • 套用範圍依目前頁序計算，留白表示全部；頁碼依範圍中的頁序連續編號。
  • 匯出所選或拆分時保留工作台顯示的頁碼與總頁數，不會在每個分檔重新編號。
  • 頁首、頁尾支援 {n}（目前頁序）、{total}（工作台總頁數）。頁首／頁尾與頁碼同位置時會自動向內避讓，也可自行調整邊界。

字型與匯出

中文字採 Windows「標楷體」（DFKai-SB），英文、數字、符號採 Times New Roman。這台 Windows 電腦可直接使用；其他裝置若未安裝字型會使用系統替代字型。新增文字以高解析透明影像寫入 PDF，保留顯示字型；原頁文字與向量仍保留。新增文字在匯出後無法像原生文字一樣搜尋或編輯。

PDF 在瀏覽器本機處理，不會上傳。首次開啟需連網載入 PDF.js、pdf-lib 與 JSZip。重新整理或關閉頁面會清除未匯出的工作；請先匯出。輸出檔名可省略 .pdf。

快捷鍵

Ctrl / Cmd + Z · Ctrl / Cmd + Y
復原 / 重做；文字輸入時使用輸入框本身的復原。
Delete / Backspace
刪除選取的註解、補丁或縮圖頁面。
Esc
關閉對話框、取消繪製或退出展開閱讀器。
